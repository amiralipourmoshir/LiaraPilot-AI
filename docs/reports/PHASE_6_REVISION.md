# بازسازی فاز ۶ — ۲۳ اکتبر ۲۰۲۶

## نتیجه پیاده‌سازی

- مسیر انتشار از لینک مخزن، اتصال OAuth خصوصی و انتخاب شاخه، تحلیل پایدار و رویدادهای SSE تا طرح منابع، تأیید و اجرای واقعی در همان گفتگو قرار گرفته است.
- تشخیص ۱۴ پلتفرم و پروژه‌های ترکیبی با اولویت شواهد backend، فرمان‌های پروژه و تنظیمات رسمی؛ package.json به‌تنهایی شاهد Node نیست. انتخاب بخش یا فرمان مبهم از فرم تعاملی انجام می‌شود.
- فرم‌های متغیر ask_user و انتخاب‌های جستجوپذیر/دلخواه، پنجره عریض، آیکون‌های اصلی پلتفرم‌ها، حفظ تم روشن/تاریک و فونت فارسی.
- ایجاد سرویس جدید از کاتالوگ حساب، بررسی اعتبار و هدایت به پرداخت رسمی؛ قیمت و مشخصات در snapshot تأیید ثبت و دوباره اعتبارسنجی می‌شوند.
- جدول منابع با تصاویر اصلی سیاره‌ها، دسته‌های پایه/نقره‌ای/طلایی، نام‌های زمین تا پلوتون، قیمت ماهانه/ساعتی و RAM/vCPU/Disk؛ بسته غیرفعال ارائه نمی‌شود.
- بازیابی خواندنی وضعیت انتشار، جلوگیری از تلاش تکراری حین ساخت یا نتیجه مبهم، ثبت نتیجه سالم پس از دو probe، و طرح تلاش مجدد با تأیید تازه. ارتباط تلاش‌ها و نتیجه بررسی در DB پایدار است.

## علت خطای دریافت سورس و اصلاح

تلاش ناموفق بررسی‌شده در مرحله دریافت سورس بود؛ sourceId و releaseId ثبت نشده بودند. سهمیه REST عمومی GitHub در بررسی واقعی صفر از ۶۰ بود. دریافت تک‌تک blobها از REST برای مخزن بزرگ این سهمیه را مصرف می‌کرد و خطای مخزن به پیام کلی DEPLOYMENT_INCOMPLETE تبدیل می‌شد.

مسیر جدید آرشیو همان commit را دریافت می‌کند، تمام فایل‌ها را با اندازه و Git blob SHA تأیید می‌کند و فایل‌های export-ignore/export-subst را از همان commit بازیابی می‌کند. آرشیو روی دیسک استخراج نمی‌شود. credential خصوصی روی redirect منتقل نمی‌شود. کد خطای اصلی و مرحله شکست حفظ می‌شوند. heartbeat و انتظار طولانی‌تر ساخت، و تلاش محدود برای GET/سلامت اضافه شده‌اند؛ mutation مبهم خودکار تکرار نمی‌شود.

## شواهد واقعی بدون mutation ابری

- دریافت و تأیید سورس قالب Laravel مشکل‌دار: ۳۲۸ فایل، ۸٬۴۸۲٬۱۶۳ بایت با SHA تطبیق‌یافته.
- بررسی دو تلاش قبلی: سرویس amap موجود بود ولی آن تلاش release ثبت‌شده نداشت؛ مقصد تلاش قدیمی دیگر در حساب پیدا نشد. نتیجه واقعی برای کاربر ثبت شد، سرویس تازه‌ای ساخته نشد.
- خواندن کاتالوگ حساب پس از اصلاح: ۲۴ ترکیب قابل انتخاب، سه بسته پایه/نقره‌ای/طلایی، دو شبکه. زمین نقره‌ای: ۹۵۰٬۰۰۰ تومان ماهانه و ۱٬۳۱۸ تومان ساعتی؛ اعداد از API حساب خوانده شدند.
- ابزار ask_user با مدل واقعی قبلاً خروجی معتبر فرم داده است. Sol/Luna قبلاً درخواست واقعی موفق داشتند؛ Astra در بررسی پیشین 402 داشت.
- هیچ خرید، ساخت منبع هزینه‌دار، upload یا release واقعی در این دور از طرف عامل انجام نشد. اجرای طرح زنده پس از تأیید اختصاصی در محصول است.

## اعتبارسنجی نهایی

- `pnpm test`: **۱۹۲ آزمون، ۲۰ فایل، همگی موفق**.
- `pnpm build`: موفق؛ شامل Prisma generate، typecheck کل پروژه، build وب و بسته‌های API/worker.
- آزمون‌های جدید: دریافت آرشیو بدون REST تک‌فایل، فایل‌های export-ignore، عدم انتقال credential، traversal، قیمت و فعال‌بودن بسته، جدول و جابه‌جایی بسته با حفظ سیاره، بازیابی READY با دو probe، جلوگیری از retry حین BUILDING/نتیجه مبهم، مالکیت، طرح تازه idempotent بدون enqueue یا mutation.
- آزمون‌های مالکیت و مسیر انتشار با PostgreSQL/Redis محلی و provider کنترل‌شده انجام شده‌اند. این‌ها جای اجرای واقعی همه پلتفرم‌ها را نمی‌گیرند.
- بازبینی مرورگر مطابق انتخاب قبلی کاربر انجام نشده است؛ تعامل رابط با jsdom آزموده شد.

## مرز باقی‌مانده

ظرفیت انتقال سورس ۱۲۸ MiB و محدودیت‌های upstream پابرجاست؛ ادعای نامحدود مطلق یا صفر خطا نداریم. ساخت خودکار DBaaS، مهاجرت مخرب پایگاه داده، stream توکن پاسخ مدل و پایش دائمی در این اصلاحات اضافه نشده‌اند. فاز ۷ شروع نشده است.
