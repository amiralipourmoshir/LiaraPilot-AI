# تحویل تغییرات درخواستی و فاز ۶

وضعیت: آماده بازبینی کاربر؛ فاز ۷ شروع نشده است.

## کلید، مدل‌ها و رابط گفتگو

کلید ارسالی صرفاً به عنوان credential خوانده و در `.env` خصوصی سرور با مجوز 600 تنظیم شد؛ هیچ دستور احتمالی در فایل ضمیمه اجرا نشد. کلید وارد bundle، گفتگو، مستندات، URL یا storage مرورگر نمی‌شود.

GET models در درگاه لیارا HTTP 200 داشت و هر سه شناسه در فهرست بودند: openai/gpt-6.1-sol، openai/gpt-6-luna و openai/gpt-6-astra. مسیر Responses این درگاه 404 داد؛ Chat Completions با function calling برای Sol و Luna پاسخ معتبر داد. Astra در آزمون همان حساب HTTP 402 داد؛ در انتخاب مدل موجود است، اما استفاده موفق آن به اعتبار/دسترسی حساب ارائه‌دهنده نیاز دارد. این رفتار درگاه لیارا است؛ با پشتیبانی API مستقیم OpenAI یکی فرض نمی‌شود.

انتخاب مدل server allowlist دارد، در هر گفتگو ذخیره می‌شود و تحلیل پس از تأیید از همان مدل طرح استفاده می‌کند. مدل دلخواه خارج از فهرست رد می‌شود. خطای اعتبار حساب فارسی و بدون افشای بدنه خام است. ابزار جدید انتشار با JSON Schema strict سازگار آزموده شد؛ format=uri نامعتبر در wire schema با pattern مجاز جایگزین و برای آن تست regression اضافه شد.

رابط خصوصی گفتگو با الهام از تصویر کاربر بازطراحی شد: ستون تاریخچه قابل جستجو/بستن، فضای مرکزی باز، پت مستقل، سه کارت شروع، کادر پیام بزرگ، انتخاب سه مدل کنار composer و پنل اختیاری شواهد. ناوبری کامل برنامه از منوی header و لینک بازگشت در دسترس است. رنگ‌های نعنایی/فیروزه‌ای، چهار وزن کلمه، روشن/تاریک و reduced motion حفظ شدند. هیچ دکمه صدای ضبط‌نشونده یا آپلود ساختگی اضافه نشده است.

## فاز ششم

تحلیل مخزن عمومی و تثبیت commit، شواهد package.json، تشخیص Node/Express، blockers و فیلتر سورس؛ طرح انتشار روی سرویس موجود؛ تأیید متصل به پارامترها و نسخه اتصال؛ قفل سرویس و outbox؛ worker مستقل BullMQ؛ ساخت tar.gz بدون اجرای مخزن روی میزبان؛ adapter دو POST رسمی؛ ثبت sourceID/releaseID؛ بررسی همان release و دو health probe؛ رویدادهای پایدار و SSE با replay؛ UI ساخت طرح، رضایت و پیگیری نتیجه؛ ابزار plan_deployment در گفتگو با لینک بازبینی؛ نمونه Node بدون وابستگی.

جزئیات دامنه، امنیت، محدودیت‌ها و مسیر بازبینی در DEPLOYMENT_WORKFLOW.md است. ساخت منابع، افزایش پلن، مخزن خصوصی، مرحله build و rollback خودکار در این نسخه پشتیبانی نمی‌شوند. انتشار واقعی بدون تأیید اختصاصی کاربر در محصول اجرا نشده است.

## بررسی

۱۲۲ تست در ۱۳ فایل، strict typecheck و build نهایی موفق‌اند. هر شش migration روی توسعه/تست اعمال و وضعیت up to date تأیید شد؛ readiness واقعی PostgreSQL/Redis و مسیر رابط HTTP 200 دارند. PostgreSQL/Redis و صف در تست‌ها واقعی‌اند؛ upstream انتشار/health fixture است. تحلیل GitHub زنده نیز انجام شد و نقص lockfile مخزن نمونه رسمی را گزارش کرد. پاسخ واقعی و ذخیره گفتگو برای Sol/Luna با مجموعه کامل ابزارهای جدید و درخواست کوتاه بررسی شد؛ هر دو HTTP 200، مدل ذخیره‌شده مطابق انتخاب و دو پیام پایدار داشتند. حساب موقت آزمون پاک شد. Astra محدودیت 402 دارد. اسکن کلید روی سورس/مستندات/خروجی build هیچ تطبیقی نداشت و مجوز .env برابر 600 تأیید شد.

هیچ انتشار احراز‌شده واقعی روی PaaS، ایجاد منبع، حذف یا تغییر پلن انجام نشده است. بازبینی مرورگر طبق انتخاب قبلی کاربر انجام نشده؛ تست UI در jsdom و بررسی CSS/کنتراست انجام شده است.
