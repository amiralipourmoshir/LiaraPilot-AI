# اصلاح رابط گفتگو — پس از فاز ۶

دامنه درخواست: فقط رابط چت؛ فاز ۷ شروع نشده است.

- رندر مشترک Markdown برای پاسخ دستیار واقعی/دمو و متن تحلیل: CommonMark و GFM، تیتر، تأکید، لیست، جدول، نقل‌قول، خط جداکننده، inline code و بلوک کد با syntax highlighting و کپی متن اصلی. نمایش RTL و کد LTR، هر دو تم و فونت کلمه حفظ شدند.
- parser خروجی را به عناصر React تبدیل می‌کند؛ HTML خام اجرا نمی‌شود، URLهای اجرایی فیلتر و تصاویر خارجی به شرح متنی تبدیل می‌شوند تا بارگیری خودکار نداشته باشند. لینک خارجی rel=noopener noreferrer دارد. کد فقط نمایش داده می‌شود و اجرا نمی‌شود.
- ارتفاع پوسته و محتوا از فضای واقعی باقی‌مانده پس از نوارهای بالا گرفته می‌شود؛ height ثابت مبتنی بر تفریق یک نوار حذف شده و min-heightهای قبلی مهار شده‌اند. html/body/root فقط هنگام حضور صفحه دستیار خصوصی overflow:hidden دارند و هنگام خروج آزاد می‌شوند. اسکرول عمودی صفحه فقط در پیام‌هاست؛ اسکرول افقی قطعه کد/جدول داخل همان پیام محصور است.
- ستون راست اسکرول مستقل ندارد؛ تعداد گفتگوهای هر صفحه با ارتفاع موجود تنظیم می‌شود و دکمه قبلی/بعدی و جستجو دسترسی به تاریخچه کامل را حفظ می‌کنند. هدایت خودکار پاسخ، scrollTop همان بخش پیام‌ها را تغییر می‌دهد و از scrollIntoView کل صفحه استفاده نمی‌کند.
- منوی مدل با Radix Select و گزینه‌های قابل استفاده با صفحه‌کلید ساخته شد؛ نشان محلی ChatGPT کنار انتخاب فعلی و هر مدل است. انتخاب و ارسال شناسه مدل به API حفظ شدند.

بررسی: ۲۹ تست رابط/داده در ۵ فایل با pnpm test:ui موفق‌اند؛ pnpm build و strict typecheck موفق‌اند. شش تست جدید شامل semantic Markdown، highlight/کپی، XSS/تصویر رهگیر، زبان ناشناخته/خطای clipboard، اسکرول محدود به پیام و قفل/آزادسازی viewport هستند. تست انتخاب مدل برای منوی جدید و وجود آیکون هر گزینه به‌روز شد. هیچ API مدل واقعی یا انتشار ابری برای این اصلاح فراخوانی نشده است.

بازبینی مرورگر طبق انتخاب قبلی کاربر انجام نشده؛ تست‌های DOM/jsdom جای اندازه‌گیری بصری مرورگر را نمی‌گیرند. CSS فضای پوسته/نوارها و اندازه‌های کوچک اصلاح شد، اما نتیجه اندازه‌گیری viewport در مرورگر ادعا نمی‌شود.
