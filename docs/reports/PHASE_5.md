# تحویل فاز ۵ — دستیار ماندگار و تأیید متصل به طرح

وضعیت تاریخی: طبق درخواست بعدی کاربر، اتصال مدل و ظاهر گفتگو تکمیل شد و فاز ۶ آغاز شد؛ گزارش جدید در PHASE_6.md.

## خروجی

- بسته ai-agent با provider قابل تعویض برای Responses و OpenAI-compatible Chat Completions، ابزارهای strict، محدودیت تعداد فراخوانی، حجم و زمان و خطاهای پالایش‌شده.
- Conversation، ChatMessage، ChatRun، AssistantPlan و AssistantEvidence با migration واقعی PostgreSQL.
- گفتگو و فهرست اخیر، انتخاب سرویس، لینک مستقیم از جزئیات سرویس، حالت تنظیم‌نبودن مدل، بازیابی گفتگو بعد از refresh و نمایش شواهد.
- طرح زمان‌دار و یک‌بارمصرف با hash پارامترها، نسخه credential، سیاست و مقصد مدل؛ لغو و رد replay/دستکاری/تغییر اتصال/ارائه‌دهنده.
- فرم رضایت صریح با سرویس، داده‌ها، بازه ثابت، مقصد تحلیل و مهلت تأیید؛ هر دو تم، فونت کلمه و پت موجود حفظ شدند.
- اجرای خواندن اطلاعات سرویس، ۵ انتشار و ۳۰ خط لاگ پس از تأیید؛ گزارش تفکیک‌شده مشاهدات، فرضیه‌ها، شواهد ناکافی و پیشنهادها.
- دوام پیام و شواهد، idempotency، lease گفتگو و ثبت وضعیت ناقص پس از خطا یا قطع اجرا؛ بدون retry پنهان.

## مسیر بازبینی

مدل را طبق AI_ASSISTANT.md در سرور تنظیم کنید ← وارد فضای شخصی شوید ← در صورت نیاز حساب لیارا را از فرم اختصاصی متصل کنید ← دستیار ← سرویس ← «برای بررسی این سرویس یک طرح آماده کن» ← بازبینی طرح ← رضایت ارسال شواهد ← تأیید ← مشاهده گزارش و باز کردن شاهد ← refresh یا بازگشت از فهرست گفتگوهای اخیر.

برای لغو، در پنجره بازبینی «لغو طرح» را بزنید. تغییر credential یا مدل پس از تهیه طرح، تأیید قبلی را معتبر نمی‌کند. دمو همچنان مستقل است و پاسخ‌های ثابت را با برچسب نمایش می‌دهد.

## بررسی و محدودیت

۸۸ تست در ۱۰ فایل، strict typecheck و build موفق‌اند. هر سه migration روی دیتابیس توسعه و تست اعمال شده‌اند و readiness واقعی PostgreSQL/Redis موفق است؛ جزئیات در TESTING.md. تست‌های شبکه مدل/لیارا fixture هستند؛ PostgreSQL و Redis تست واقعی‌اند. کلید مدل واقعی ارائه نشده است؛ پاسخ احراز‌شده واقعی مدل و تحلیل سرویس زنده تأیید نشده‌اند. بازبینی مرورگر طبق انتخاب قبلی کاربر انجام نشده؛ تست رابط jsdom است.

این مرحله ابزار تغییر ابری ندارد. جریان تأیید روی بررسی خواندنی و اشتراک داده اعمال شده است؛ pipeline تأیید deployment و worker فاز ۶ هنوز ساخته نشده است. ارجاع مدل به شاهد موجود کنترل می‌شود، اما صحت معنایی تشخیص تضمین نمی‌شود. استریم توکن/SSE، پایش پس‌زمینه، health check و incident در این فاز ادعا نمی‌شوند.
