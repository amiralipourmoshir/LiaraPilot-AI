# وضعیت فاز ۷

پیاده‌سازی چهار بخش بر پایه اتصال زنده موجود ادامه یافت؛ داده نمونه به‌عنوان داده واقعی اضافه نشده است.

افزوده‌ها:
- برنامه تست قابل تأیید، صف پایدار و اجرای worker با سقف پوشش و زمان.
- گزارش مسیر، وضعیت HTTP، زمان DOM/load، تعداد درخواست، حجم پاسخ، خطای مرورگر و جزئیات فایل‌ها؛ نمودار و خروجی JSON.
- نمودار CPU/حافظه از قرارداد موجود لیارا با نمایش صریح واحد تأییدنشده.
- رخداد SCAN مستقل از HEALTH، شواهد در تشخیص مدل و کنترل پوشش مسیرها برای تأیید بازیابی.
- دستور صریح اصلاح فایل تحلیل‌شده، تولید unified patch، دانلود، تأیید متصل به hash و انقضا، commit با کنترل SHA و آندو مستقل.
- ثبت اقدامات در تاریخچه با لینک به آزمایشگاه سرویس و دسترسی از جزئیات رخداد.

اعتبارسنجی در محیط محلی:
- `pnpm test`: ۲۹ فایل، ۲۱۶ تست موفق.
- مجموعه متمرکز پایش/پچ: ۴ فایل، ۳۰ تست موفق.
- `pnpm build`: تولید وب، API و worker موفق.
- migrationهای دیتابیس توسعه و تست اعمال شدند.

مرز اعتبارسنجی: GitHub transport و scanner در تست‌ها کنترل‌شده‌اند. دانلود Chromium با 403 منطقه‌ای CDN متوقف شد؛ اسکن واقعی مرورگر و commit/undo واقعی GitHub تأیید نشده‌اند. هیچ انتشار یا تغییر کد در سرویس واقعی انجام نشده است. بازبینی دیداری پنل احرازشده نیز در این اجرا انجام نشده است. فاز ۷ کامل‌شده اعلام نمی‌شود.
