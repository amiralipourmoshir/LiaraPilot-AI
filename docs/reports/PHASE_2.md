# تحویل فاز ۲ — زیرساخت و دسترسی

وضعیت: فاز ۲ با درخواست کاربر برای ورود به فاز ۳ تأیید شد؛ این سند گزارش زمان تحویل فاز ۲ است. فاز ۱ با پیام کاربر تأیید شد. دو الزام افزوده‌شده: هر دو تم روشن/تاریک و استفاده از چهار فونت KalamehFaNum ارسالی.

## ساخته‌شده

- pnpm monorepo با React/Vite، Fastify، worker مستقل و بسته‌های shared/database/security/jobs.
- strict TypeScript، Zod، Prisma 7.10.1 پایدار (به‌جای نسخه RC جدید registry)، PostgreSQL 16، Redis 7 و BullMQ 5.
- ثبت‌نام/ورود/خروج، Argon2id، نشست hash‌شده پایدار، HttpOnly/SameSite، Secure در production، کنترل Origin/CSRF، نرخ درخواست و headerهای امنیتی.
- پروژه شخصی، کنترل مالکیت API و FK مرکب دیتابیس، audit پایه.
- عملیات بررسی محلی با transaction/outbox، کلید idempotency، صف واقعی و worker قابل راه‌اندازی مجدد، event و نتیجه ذخیره‌شده.
- رابط آغاز کار فارسی/RTL، فرم‌های معتبر، تم روشن/تاریک/سیستم پایدار، فونت‌های Regular/Medium/SemiBold/Bold، نمایش حالت خالی/انتظار/خطا/نتیجه.
- Docker Compose، helper محلی برای محیط بدون daemon، env نمونه، OpenAPI و راهنمای اجرای این بخش.

## مسیر قابل استفاده

ثبت‌نام ← ورود خودکار ← ساخت پروژه شخصی ← ثبت بررسی زیرساخت ← دریافت کار در worker ← ذخیره نتیجه ← refresh با لینک همان عملیات ← خروج ← ورود دوباره.

## شواهد

۱۹ تست واقعی پاس شدند؛ build و typecheck موفق، migration روی دیتابیس‌ها اجرا شده و readiness از API buildشده پاسخ 200 داده است. جزئیات در TESTING.md.

بازبینی مرورگر به درخواست کاربر انجام نشده است؛ کیفیت ظاهری هنوز نیازمند مشاهده انسانی است. فایل فونت‌ها دقیقاً با ورودی‌های ارسالی یکسان‌اند. هیچ اتصال Liara، LLM یا انتشار واقعی ادعا نمی‌شود.

## محدودیت‌های همین بخش

- صفحه فعلی فضای شروع کار است؛ داشبورد، AI workspace، مدیریت عملیات ابری و سیستم طراحی گسترده در فاز ۳ و مراحل بعد هستند.
- schema فقط موجودیت‌های لازم این بخش را دارد؛ طراحی کامل DATA_MODEL.md به‌تدریج migration می‌شود.
- rate limit فعلاً در حافظه یک API process است؛ برای چند replica باید مشترک شود.
- MFA، تأیید ایمیل و بازیابی رمز در این بخش پیاده نشده‌اند. نشست منقضی رد می‌شود؛ job پاک‌سازی retention در آینده اضافه خواهد شد.
- polling جای SSE آینده را نگرفته؛ فقط نمایش نتیجه بررسی محلی این فاز است.
- Docker Compose نوشته شده، اما در این محیط daemon موجود نبود و اجرای آن تست نشد؛ سرویس‌های واقعی مستقل محلی برای تست استفاده شدند.
