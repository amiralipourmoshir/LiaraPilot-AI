# تحویل فاز ۴ — اصلاح آواتار و اتصال امن لیارا

وضعیت تاریخی: توسط کاربر تأیید شد و فاز ۵ آغاز شد. تأیید فاز ۳ همراه درخواست اصلاح سر ربات دریافت شد.

## اصلاح درخواستی سر ربات

فایل مستقل `apps/web/public/brand/pilot-head.png` با ابزار داخلی image_gen و مرجع شخصیت اصلی ساخته شد؛ سر و آنتن کامل، بدون بدن یا تکه گردن، روی زمینه شفاف. تصویر ۱۲۵۴×۱۲۵۴ است و آلفای آن بازه ۰ تا ۲۵۵ دارد. فایل تمام‌قد حفظ شد. `Mascot` در حالت آواتار و favicon از فایل سر استفاده می‌کنند؛ بزرگ‌نمایی، offset، overflow crop و ماسک CSS حذف شدند. پرامپت دقیق در design/head-prompt.txt و hash در design/assets.json است.

## ساخته‌شده در این فاز

- adapter واقعی GET برای اعتبارسنجی اتصال، سرویس‌ها، جزئیات، لاگ، نسخه‌ها و خلاصه خام منابع؛ مقصد ثابت رسمی و response validation.
- انواع تولیدشده از OpenAPI؛ پشتیبانی از قالب جدید v2 لاگ براساس سورس رسمی CLI و fallback محدود به v1.
- migration واقعی ProviderConnection، Credential و Application با مالکیت مرکب user/mode و قیود FK.
- توکن رمزگذاری‌شده AES-GCM با کلید مستقل و نسخه‌بندی، nonce تصادفی و AAD متصل به مالک و اتصال.
- کنترل نشست، Origin/CSRF، مالکیت، محدودیت نرخ و سقف زمان/حجم؛ جلوگیری از افشای envs، توکن و بدنه خطای provider.
- اتصال/جایگزینی اعتبارسنجی‌شده، همگام‌سازی، حفظ snapshot آخرین موفقیت، علامت‌گذاری سرویس غایب، قطع اتصال و حذف credential، جلوگیری از احیای اتصال با پاسخ دیررس.
- فرم اختصاصی masked با حذف مقدار پس از ارسال؛ توکن وارد mutation cache، URL، localStorage یا گفتگو نمی‌شود.
- فضای LIVE مستقل از دمو: فهرست سرویس‌ها و تب‌های اطلاعات، لاگ، نسخه و منابع. metricها بدون تبدیل واحد تأییدنشده نمایش داده می‌شوند.
- راه‌انداز امن کلید محلی (`pnpm secrets:init`) و مستندات اتصال/امنیت/محدودیت‌ها.

## مسیر بررسی

۱. ورود به حساب شخصی ← اتصال‌ها ← اتصال امن حساب لیارا.
۲. وارد کردن توکن فقط در فرم اختصاصی و teamId در صورت نیاز.
۳. اعتبارسنجی و ذخیره رمزگذاری‌شده ← مشاهده شمار سرویس‌ها ← دیدن سرویس‌ها.
۴. باز کردن سرویس ← دریافت جزئیات، لاگ‌ها، نسخه‌ها یا خلاصه منابع از API واقعی.
۵. بازگشت به اتصال‌ها ← همگام‌سازی یا قطع اتصال ← حذف توکن ذخیره‌شده بدون تغییر در سرویس ابری.

## شواهد و حدود تأیید

۶۴ تست در ۷ فایل: تست‌های قبلی به‌علاوه crypto/redaction، قرارداد adapter، خطاهای provider، هر دو قالب لاگ و مالکیت/دوام اتصال در PostgreSQL واقعی؛ تست فرم و گردش صفحات در jsdom با API mock. typecheck، build و دو migration روی دیتابیس توسعه و تست بررسی شده‌اند.

توکن واقعی ارائه نشده؛ **اتصال احراز‌شده زنده هنوز تأیید نشده است**. هیچ credential واقعی از عامل دریافت نشده و هیچ منبع ابری ایجاد/منتشر/حذف نشده است. بازبینی مرورگر طبق انتخاب قبلی کاربر انجام نشده؛ خود تصویر سر با ابزار تصویر مشاهده شد.

## موارد موکول‌شده

اتصال مدل و رجیستری ابزار، ماندگاری گفتگو و approval در فاز ۵؛ تحلیل GitHub و انتشار تأییدشده در فاز ۶؛ health checks و تشخیص/اصلاح واقعی در فاز ۷. پیاده‌سازی عملیات تغییردهنده در این فاز عمداً تا آماده شدن approval فعال نشده و به عنوان قابلیت کامل علامت نخورده است.
