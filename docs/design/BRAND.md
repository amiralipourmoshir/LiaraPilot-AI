# هویت بصری پایلوت

## ورودی و خروجی

- مرجع: لوگوی SVG ارسالی کاربر، نسخه بدون تغییر در `apps/web/public/brand/liara-logo.svg`.
- شخصیت: «پایلوت»، یک ربات همراه با سر مکعبی سه‌تکه، چشم‌های نعنایی و بدنه سفید سرامیکی.
- خروجی اصلی: `apps/web/public/brand/pilot-mascot.png`، تصویر رندر سه‌بعدی RGBA با ابعاد ۱۲۵۴×۱۲۵۴ و زمینه شفاف؛ حدود ۹۷۲ KiB.
- روش تولید: ابزار داخلی **image_gen**؛ CLI یا API key شخصی استفاده نشد.
- پرامپت دقیق: [mascot-prompt.txt](mascot-prompt.txt).
- اطلاعات فایل و SHA-256: [assets.json](assets.json).

لوگوی مرجع پیش از تولید برای مشاهده، بدون تغییر بصری از SVG به PNG تبدیل شد. فرم سه وجه جدا و پالت سبز نعنایی تا فیروزه‌ای، مبنای طراحی شخصیت بودند. تصویر تولیدشده بازبینی و آلفای آن با دامنه ۰ تا ۲۵۵ بررسی شد؛ فایل اصلی در پروژه کپی شده است.

## کاربرد در محصول

کامپوننت مشترک `Mascot` تنها منبع نمایش شخصیت است: نشان برنامه و favicon، آواتار منوی دستیار، کارت معرفی داشبورد، صفحه ورود، گفتگوی دستیار، کارت پیشنهاد تشخیص، حالت انتظار و صفحه‌های خالی. از اصلاح فاز ۴، آواتار و favicon از فایل مستقل `pilot-head.png` استفاده می‌کنند؛ فایل سر با image_gen ساخته شده و بدون برش، ماسک یا بزرگ‌نمایی CSS نمایش داده می‌شود. نسخه تمام‌قد همچنان از فایل اصلی استفاده می‌کند. آیکون‌های عملیاتی مانند هشدار، انتشار و جستجو معنای خود را حفظ می‌کنند.

رندر شخصیت با PNG ارائه می‌شود و حرکت آرام آن در UI با Motion پیاده شده است. در ترجیح reduced-motion، شناوری غیرفعال می‌شود. تصویر هیچ اطلاعات عملیاتی یا وضعیت سلامت را به‌تنهایی منتقل نمی‌کند؛ متن و آیکون وضعیت همیشه جداگانه وجود دارند.

## رنگ و تایپوگرافی

accentها با مرجع لیارا هماهنگ شدند. تیره: پس‌زمینه `#0b1118`، سطح `#111a24` و accent نعنایی `#72e3cc`. روشن: پس‌زمینه `#f5f7f9`، سطح سفید و accent خوانای `#08796d`. دکمه اصلی برای کنتراست متن سفید، سبز تیره‌تر دارد.

چهار فایل KalamehFaNum ارسالی با وزن‌های ۴۰۰، ۵۰۰، ۶۰۰ و ۷۰۰ به‌صورت محلی استفاده می‌شوند. اندازه متن عملیاتی عموماً ۱۲ تا ۱۴ و تیتر بخش‌ها ۱۶ تا ۱۸px است؛ شناسه‌ها و لاگ‌ها LTR هستند.

۱۰ جفت‌رنگ متن/سطح برای هر دو تم با فرمول luminance بررسی شده‌اند؛ نسبت‌ها در [contrast.json](contrast.json) ثبت‌اند و همگی از حد ۴٫۵:۱ عبور می‌کنند. این محاسبه، بررسی تصویری کامل یا تأیید دسترس‌پذیری تمام اجزای صفحه نیست.

```sh
python3 scripts/check_design.py
```

## اصلاح سر در فاز ۴

سر مستقل: `apps/web/public/brand/pilot-head.png`؛ PNG شفاف ۱۲۵۴×۱۲۵۴ با آنتن کامل و لبه پایین تمیز. پرامپت دقیق [head-prompt.txt](head-prompt.txt)، روش تولید identity-preserve با ابزار داخلی image_gen و مرجع شخصیت اصلی است. فایل جدید در asset manifest ثبت شد و رندر تمام‌قد دست‌نخورده باقی ماند.

## نشان مدل‌های گفتگو

آیکون گره ChatGPT/OpenAI به صورت SVG محلی در `apps/web/public/brand/chatgpt.svg` ذخیره و کنار مدل انتخابی و هر سه گزینه نمایش داده می‌شود. منبع: [Simple Icons 13.21.0](https://github.com/simple-icons/simple-icons/blob/13.21.0/icons/openai.svg). از CSS mask برای خوانایی در دو تم استفاده می‌شود؛ فرم نشان تغییر نکرده است. فایل در manifest hash ثبت شده و در زمان اجرا درخواست خارجی برای آیکون ارسال نمی‌شود.
