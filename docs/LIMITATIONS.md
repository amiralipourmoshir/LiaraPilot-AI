# وضعیت جاری — فاز ۶

رابط فارسی، فونت KalamehFaNum، هر دو تم و دارایی مستقل سر پت حفظ شده‌اند. تصاویر رسمی ۱۴ پلتفرم از نشانی‌های ارسالی کاربر در public/platforms ذخیره شده‌اند. انتخاب‌های ویزارد جستجوپذیر و پنجره‌های تعاملی بزرگ‌ترند.

گفتگو و ابزارهای واقعی از مدل سرور استفاده می‌کنند. Sol/Luna قبلاً درخواست واقعی و function calling موفق داشتند؛ ask_user نیز با مدل واقعی بررسی شد. Astra در آزمون قبلی HTTP 402 داشت. برای این درگاه Chat تنظیم شده است؛ stream تایم‌لاین عملیات وجود دارد، ولی stream توکن‌های پاسخ مدل هنوز پیاده نشده است. حذف رازهایی که کاربر اشتباهاً در گفتگو می‌نویسد best effort است؛ فرم‌های اختصاصی محرمانه به مدل وصل نیستند.

بررسی مخزن سقف قبلیِ ۵۰۰ فایل/۵ MiB/۲ MiB برای فایل عادی را ندارد. metadata و فایل‌های تنظیمات به شکل مرحله‌ای خوانده می‌شوند؛ محدودیت‌های GitHub، پاسخ بسیار بزرگ upstream، شبکه، مسیر ناامن و ساختار نامعتبر همچنان ممکن‌اند. انتقال سورس برای انتشار فعلاً به ظرفیت ۱۲۸ MiB در حافظه محدود است و با تحلیل مخزن فرق دارد. symlink/submodule در مسیر انتشار پشتیبانی نمی‌شود.

۱۴ پلتفرم استاندارد لیارا در تشخیص، رجیستری UI و قرارداد ساخت/release پوشش داده شده‌اند. Laravel/Django همراه package.json به‌عنوان Node فرض نمی‌شوند. در چند بک‌اند مستقل یا فرمان نامشخص، فرم انتخاب نمایش داده می‌شود. تشخیص استاتیک جای اجرای build واقعی را نمی‌گیرد؛ سازگاری تمام کتابخانه‌ها و همه حالت‌های SSR/monorepo تضمین نیست. Expo/Mobile خروجی APK را روی وب اجرا نمی‌کند.

کاتالوگ و شبکه‌های حساب متصل واقعاً خوانده شدند؛ داشتن سرویس قبلی شرط ساخت سرویس نیست. شارژ حساب در کنسول رسمی لیارا انجام می‌شود، سپس وضعیت دوباره از سرور خوانده می‌شود. پرداخت موفق از روی دکمه کاربر حدس زده نمی‌شود. پایگاه داده و دیسک اختصاصی، اگر نیازشان تشخیص داده شود، هنوز باید جداگانه آماده شوند؛ ساخت خودکار DBaaS یا مهاجرت مخرب دیتابیس ادعا نمی‌شود.

ساخت منبع، تنظیم env، upload/release، approval، صف و HTTP verification با provider fixture و PostgreSQL/Redis واقعی آزموده شده‌اند. هیچ سرویس هزینه‌دار واقعی در این دور از طرف عامل ساخته یا پرداخت نشده است؛ تأیید عملیات زنده در رابط محصول لازم است. READY به‌تنهایی موفقیت نیست. پاسخ غیرخالی 200 نیز فقط دسترسی وب را نشان می‌دهد. restart/delete/resize/rollback خودکار یا دامنه سفارشی سلامت در این فاز اضافه نشده است.

بررسی واقعی مخزن Laravel ارسالی/استفاده‌شده، MegaPulse و کاتالوگ لیارا انجام شده است. بازبینی مرورگر مطابق درخواست قبلی کاربر انجام نشده؛ آزمون تعامل در jsdom و build انجام می‌شود. فاز ۷ آغاز نشده است. جزئیات و شواهد در reports/PHASE_6_REVISION.md ثبت می‌شوند.

بازیابی نتیجه از مسیر خواندنی سرویس/release و دو probe وب انجام می‌شود. تلاش دوباره طرح تازه با تأیید تازه است؛ هیچ تضمین «بدون خطا» یا تکرار بی‌نهایت عملیات ابری وجود ندارد. علت دریافت ناموفق سورسِ تلاش بررسی‌شده، اتمام سهمیه REST عمومی GitHub بود؛ انتقال آرشیویِ تأییدشده جای دریافت REST تک‌تک فایل‌ها را گرفته است. این تغییر محدودیت‌های upstream یا ظرفیت انتقال را حذف نمی‌کند.

نام و طراحی پلن‌ها با کنسول لیارا هماهنگ شده‌اند؛ مشخصات و قیمت و فعال‌بودن بسته از کاتالوگ حساب خوانده می‌شوند. فهرست و قیمت‌ها ممکن است توسط لیارا تغییر کنند و هنگام تأیید مجدداً بررسی می‌شوند.
