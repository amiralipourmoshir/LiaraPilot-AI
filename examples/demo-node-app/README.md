# نمونه انتشار LiaraPilot

این پوشه یک برنامه Node بدون وابستگی و بدون مرحله build است. برای استفاده از مسیر انتشار، فایل‌های این پوشه را در ریشه مخزن عمومی خود قرار دهید. برنامه روی سرور عامل اجرا یا خودکار منتشر نمی‌شود.

```sh
npm start
```

پورت پیش‌فرض 3000 (یا PORT)، مسیر بررسی `/health` و متن مورد انتظار `liarapilot-demo-healthy` است. برای انتشار، یک سرویس Node.js موجود متعلق به خودتان انتخاب و طرح را در برنامه بازبینی کنید. هزینه حساب و اثر جایگزینی نسخه را پیش از تأیید بررسی کنید.
